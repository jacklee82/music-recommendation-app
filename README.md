# 음악 추천 챗봇 웹앱

## 🎵 프로젝트 개요

AI 기반 음악 추천 챗봇 웹앱입니다. 사용자의 감정, 상황, 선호도를 분석하여 맞춤형 음악을 추천해주는 인터랙티브한 웹 애플리케이션입니다.

## 🚀 주요 기능

### 1. 지능형 음악 추천
- **감정 기반 추천**: 슬픔, 기쁨, 분노, 설렘 등 감정 상태별 맞춤 추천
- **상황 기반 추천**: 운동, 퇴근, 여행, 작업 등 상황별 적합한 음악
- **계절/날씨 기반 추천**: 봄, 여름, 가을, 겨울 및 날씨별 분위기 음악
- **개인화 추천**: 사용자 선호도 학습 및 피드백 반영

### 2. 인터랙티브 채팅 인터페이스
- **자연스러운 대화**: 자연어 처리를 통한 직관적인 상호작용
- **실시간 추천**: 즉시 분석 및 추천 결과 제공
- **시각적 피드백**: 로딩 애니메이션 및 추천 이유 표시
- **빠른 제안**: 인기 질문 버튼으로 쉬운 시작

### 3. 아름다운 UI/UX
- **모던 디자인**: 그라데이션과 글래스모피즘 효과
- **반응형 레이아웃**: 모바일부터 데스크톱까지 완벽 지원
- **부드러운 애니메이션**: Framer Motion을 활용한 자연스러운 전환
- **직관적인 인터페이스**: 사용하기 쉬운 채팅 형태

## 🛠️ 기술 스택

### Frontend
- **React 18**: 최신 React 기능 활용
- **TypeScript**: 타입 안정성 보장
- **Styled Components**: CSS-in-JS 스타일링
- **Framer Motion**: 부드러운 애니메이션
- **Lucide React**: 아이콘 라이브러리

### 추천 엔진
- **키워드 매칭**: 감정, 상황, 장르 키워드 분석
- **점수 기반 정렬**: 다중 기준 점수 계산
- **개인화 알고리즘**: 사용자 선호도 반영
- **실시간 분석**: 즉시 키워드 추출 및 매칭

## 🎯 사용 방법

### 1. 기본 사용법
1. 웹앱에 접속
2. 채팅창에 원하는 음악 상황을 입력
3. AI가 분석하여 맞춤형 추천 제공
4. 추천된 곡들의 이유와 함께 확인

### 2. 예시 질문들
- "슬플 때 듣는 노래"
- "운동할 때 듣는 음악"
- "봄날 산책할 때 듣는 노래"
- "퇴근길에 듣는 힐링 음악"
- "이별 후 마음 정리할 때 듣는 노래"

### 3. 빠른 제안 버튼
- 화면 하단의 제안 버튼을 클릭하여 인기 질문으로 빠르게 시작

## 📁 프로젝트 구조

```

├── components/
│   └── ChatInterface.tsx      # 메인 채팅 인터페이스

│   └── questions.ts           # 질문 및 추천곡 데이터

│   └── index.ts              # TypeScript 타입 정의

```
